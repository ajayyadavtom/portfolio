# Ajay M — Portfolio

Personal video-portfolio site for **Ajay M** — full-stack developer & AI builder, Bengaluru.

A single self-contained static site: the hero video, portrait and all styles are embedded, so it
runs offline and deploys anywhere. Built from my GitHub projects and profile.

**Live:** https://ajayyadavtom.github.io/portfolio/

## Sections
- Hero (generated video + headline)
- About
- What I do (full-stack web, on-device AI, mobile/offline-first, fundamentals)
- Selected work (Bharat Vision, Lucy Voice Agent, Arogya Mitra 2.0, Beacon of Balance, Student Wellness App, Microsoft Learn Hub)
- Milestones
- Contact
