Bharat Vision
01 · Flagship★ 2Open source

Bharat Vision — AI transit hub for Namma Bengaluru

A next-generation, multi-modal transit ecosystem for Bengaluru, built as an offline-capable PWA. It brings BMTC bus tracking, Namma Metro token generation, dynamic route planning and a zero-network SOS into one app. Modules include the Vanara AI engine (a live Gemini-powered transit assistant), a Namma Metro hub with QR ticketing and fare calculation, an offline SafeKeep SOS that falls back to native cellular intents, and a gamified carbon-impact dashboard.

02 · AndroidOn-device AI

Lucy Voice Agent

A native Android voice assistant that runs entirely offline. It uses Vosk for offline speech-to-text, Silero VAD for wake-word detection and a TensorFlow Lite speaker-embedding model for voice authentication, with whitelist-based command execution and optional device-owner system actions.
